# Class Tracker Web
A modern student productivity and class management website.

# Website :
https://class-track-by-karthik.vercel.app

# Getting Started :
1). Open the above link

2). Select Sign Up image

3). Fill in your details image

4). Select Sign Up(no verification required) image

5). Select your timezone and select add your subjects image

6). Add and remove subjects image

7). Add your schedule and timings here image

Feel free to explore the website as you wish.

Note : For users switching accounts please go to Manage tab, inside data tab, select export data(json format) from your previous account and import into new account from the same place image

If any issues or need to reset password (this feature hasn't been implemented yet, upcoming in v2.1.0), feel free to contact me at karthikkrishnanjayakrishnan@gmail.com or report on the discussions page or follow this link #1 (comment)
